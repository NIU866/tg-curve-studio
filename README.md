# 热重曲线绘图器 · Thermal Lab

[打开在线工具](https://niu866.github.io/tg-curve-studio/)

导入 CSV、TSV 或 XLSX，选择温度与质量列，最多叠加六组数据。TG 和 DTG 图各自可导出为包含坐标、图例和曲线的 SVG。文件由浏览器处理。点击「加载示例」可体验两组模拟数据。

- 温度列请使用摄氏度。单段单调升温数据可正序或倒序存放，保留一次升温。
- 质量单位支持原始质量、百分数和 0–1 比例。原始质量换算为相对首个温度点的百分比。
- 同一温度的多个记录取平均值。DTG 取局部线性拟合的负斜率，单位为 %/°C。可为每次绘图选择计算点数。
- XLSX 支持选择工作表和读取缓存的数值。单表最多读取前 128 列及 100,000 行。单个文件最大 16 MB。
- 图面按区间保留局部极值用于缩减绘制点。计算使用全部有效点。

本地开发可运行 \`python -m http.server 8080\`，访问 http://localhost:8080/。ZIP 解压依赖 fflate，许可见 vendor 目录。
